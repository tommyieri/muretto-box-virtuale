Tell us what is wrong

A number that does not add up, a chart that does not draw, a page that makes no sense, something you expected to find and is not there. Write it here: we read the reports by hand, one by one, and the ones that describe a real defect become a fix.

What is this about

We use it for one thing only: to reply to you about this report. No list, no newsletter. If you leave it empty that is fine too.

What leaves this page

There is nothing else: no cookie, no identifier, no browsing trail. Your IP address is not kept — a hashed fingerprint of it is held for one hour, only to stop a robot from filling the queue.

How to write a useful report

  1. Where — the page, and if it matters which race or which driver.
  2. What you expected — even if it seems obvious: it almost never is.
  3. What you saw instead — the wrong number, the empty box, the text that does not add up.

Where it ends up

It ends up in a queue we read by hand. There is no automatic reply and no ticket: if the report describes a reproducible defect, it becomes a fix in the code; if it describes something we decided on purpose, and you left your email, we explain why.

One thing to know first

The simulator on this site is a game, not a prediction: over the whole race the engine and «change nothing» are indistinguishable, and we say so on the pages. If a number from the simulation does not match the real race, that is not necessarily a defect. If instead a data point does not match the real race, that one is: write to us.
