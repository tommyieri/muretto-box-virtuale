# `data/` — il grezzo importato e pinnato

Tutto ciò che sta qui è DATO ereditato dal vecchio repo (`muretto-box-virtuale`)
o prior esterno dichiarato — mai codice. La verità sull'integrità è
`MANIFEST.sha256` (regola 7, E18); il censimento unico è `INVENTARIO.md` (E24).

- `fondo/` — archivio sessioni 2018–2025 (`.json.gz`, colonnari)
- `gare_2026/` — grezzo delle gare 2026 (`ti_archive/` per sessione, `ti_cache/` giri gara)
- `storico/` — modelli del vecchio repo, SOLO riferimento storico
- `archivio/dal_futuro/` — materiale costruito a gara finita: MAI in percorsi live (E14)
- `priors/` — prior esterni con targhetta

Nomi file e cartelle SENZA spazi (E24): la regola si applica alla frontiera
d'import, i rename sono registrati in `INVENTARIO.md`.
