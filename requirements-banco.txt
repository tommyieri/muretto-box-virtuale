# requirements-banco.txt — il python3 di SISTEMA: il Mac di sviluppo e il runner della CI.
#
# Non e' una venv: e' l'interprete con cui girano `python3 sentinella.py`, le sentinelle
# in Python del banco (`test_replay.py`, `test_rc_feed.py`, `test_sosta.py`,
# `test_tele_giro.py`, `ai_lab/redazione/test_redazione.py`) e la telemetria per sessione
# (`scheduling/auto_tele_run.sh`, ogni 30 minuti sul Mac).
#
#     python3 -m pip install -r requirements-banco.txt
#     python3 test_dipendenze.py --ambiente banco
#
# QUESTO FILE NON E' UN `pip freeze`, E GLI ALTRI DUE SI'. Una venv dedicata coincide con
# cio' che serve; un python di sistema no — li' dentro c'e' anche tutto quello che serve
# ad altro, e dichiararlo intero vorrebbe dire pretendere su un runner CI pulito una
# macchina che non esiste. Qui stanno le due librerie che il codice del banco importa e
# la chiusura delle loro dipendenze, niente di piu'.
#
# ATTENZIONE AL `.venv` DEL MAC, CHE NON E' QUESTO INTERPRETE. In `~/muretto/.venv` vivono
# pandas 3.0.3 e numpy 2.5.0 — la venv del kernel, congelata a suo tempo per il modulo
# `live/` (v. live/requirements.txt). `scheduling/auto_run.sh` sceglie il python PER
# PERCORSO e su questa macchina prenderebbe QUELLA, non il python3 di sistema: se un
# giorno il launchd del Mac tornasse attivo, pubblicherebbe una gara con un pandas
# diverso da quello del VPS. Oggi non e' attivo (`launchctl list` non porta nessun
# `com.muretto.*`), e da oggi `--ambiente auto` lo direbbe a voce alta nel log invece di
# lasciarlo scoprire ai numeri.
#
# `anthropic` E' A UNA VERSIONE DIVERSA DAL VPS (qui 0.120.0, la' 0.121.0) ed e' scritto,
# non nascosto: chi pubblica gli articoli e' il VPS dal 10/08/2026, e l'allineamento di
# questa libreria non e' un invariante dichiarato da nessuna parte. Lo e' invece quello
# delle quattro numeriche (fastf1, numpy, pandas, scipy), e `test_dipendenze.py` esce 1
# se una di loro diverge fra i file: e' su quelle che riposa la riproducibilita' del pace.
#
# LA CI INSTALLA MENO DI QUESTO ELENCO, di proposito: `.github/workflows/banco.yml` mette
# solo numpy, perche' `anthropic` nel codice della redazione e' un import PIGRO e le
# sentinelle dello stile sono aritmetica pura — nessun LLM, nessuna chiave, nessuna rete.
# Sul Mac invece serve davvero: da li' un articolo si genera a mano.
